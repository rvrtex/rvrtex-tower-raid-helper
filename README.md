# Matthew Tower Helper

A utility/debug mod for Farthest Frontier (Mono) using MelonLoader.

Features:
- Enable all guard towers
- Disable all guard towers
- Spawn raids by difficulty
- Spawn specific raid groups
- Endless escalating raid mode
- Kill active raiders
- Configurable endless raid interval

## Requirements

- Farthest Frontier (Mono)
- MelonLoader

## Installation

1. Download `MattsTowerRaidHelper.dll`
2. Place it in:

Farthest Frontier (Mono)/Mods

3. Launch the game
4. Press `Home` to open the UI

## Configuration

The mod automatically creates a configuration file here:

Farthest Frontier (Mono)/UserData/MelonPreferences.cfg

You can edit this file to change:
- UI toggle key
- Enable towers key
- Disable towers key
- Endless raid toggle key
- Endless raid interval

Default keys:
- Home = Open UI
- F11 = Enable towers
- F10 = Disable towers
- F8 = Toggle endless raids

## Notes

This mod uses the game's internal raid debug systems.
